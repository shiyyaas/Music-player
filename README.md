# Minimalist Music Player

A sleek, minimalist web-based music player designed with a specific aesthetic: a warm beige background palette, sharp dark action buttons, clean spacing, and a rounded smartphone container layout.

## Features

- **Preloaded Songs:** Play, pause, and skip through a curated list of sample tracks.
- **Playback Controls:** Includes Play/Pause, Next Track, Previous Track.
- **Progress Tracking:** A synchronized progress bar that updates as the song plays, along with current and total time displays. You can seek through the track by dragging the slider.
- **Volume Control:** Adjust the playback volume with a dedicated slider.
- **Responsive & Styled UI:** Uses Tailwind CSS and Flexbox for a clean, modern layout encapsulated within a smartphone mockup container.

## Technologies Used

- **HTML5:** For semantic structure.
- **Tailwind CSS (via CDN):** For rapid, utility-first styling.
- **Vanilla JavaScript:** For playback logic, state management, and DOM manipulation (kept strictly separate from the HTML file).

## How to Run

1. Clone or download this repository.
2. The simplest way to run this is to serve the directory with a local HTTP server. For example, using Python 3:

   ```bash
   python3 -m http.server 8000
   ```

3. Open your web browser and navigate to `http://localhost:8000`.
