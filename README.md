# 🎵 Minimalist Music Player

> A sleek, minimalist web-based music player with a warm beige aesthetic, sharp dark action buttons, clean spacing, and a smartphone-style container layout.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)
![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)

---

## ✨ Features

- 🎶 **Preloaded Songs:** Play, pause, and skip through a curated list of sample tracks.
- ⏯️ **Playback Controls:** Includes Play/Pause, Next Track, and Previous Track buttons.
- ⏱️ **Progress Tracking:** A synchronized progress bar that updates as the song plays, along with current and total time displays. Seek through the track by dragging the slider.
- 🔊 **Volume Control:** Adjust the playback volume with a dedicated slider.
- 📱 **Responsive & Styled UI:** Uses Tailwind CSS and Flexbox for a clean, modern layout encapsulated within a smartphone mockup container.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Semantic structure |
| **Tailwind CSS (via CDN)** | Rapid, utility-first styling |
| **Vanilla JavaScript** | Playback logic, state management, and DOM manipulation |

> 💡 JavaScript is kept **strictly separate** from the HTML file for clean code architecture.

## 🚀 How to Run

1. **Clone or download** this repository:
   ```bash
   git clone https://github.com/shiyyaas/Music-player.git
   cd Music-player

   ```

2. **Serve the directory** with a local HTTP server. For example, using Python 3:
   ```bash
   python3 -m http.server 8000

   ```

3. **Open your browser** and navigate to:
   ```
   http://localhost:8000

   ```
